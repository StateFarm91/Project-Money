## 1. Weaknesses in the evidence system, and what was changed

1. **Build 2 "PROVEN" is structural.** `build2.closure.proof_of` marks a row proven when a
   named module exists, *some* test imports it, and it is reachable. Nothing checks that a
   test asserts the criterion. **37 of the 227 PROVEN rows cite no test file at all.** The
   ledger rule was not changed (acceptance criteria are never changed). The spot audit (§2)
   measures how often this rule over-claims.
2. **The board never used its own `changed` set.** It computed which modules differ from the
   deployed commit and then ignored that list. A module edited after the deploy still counted
   as deployed. Fixed in `completion_board_final.py:260`. It now diffs against the working
   tree, so an uncommitted edit doesn't count as deployed either.
3. **A row whose criterion needs production evidence (class B) could be verified on tests
   alone.** The audit now checks every verified row whose criterion matches the class-B
   phrase patterns (15 rows) and records a production reading for each, or gives the reason
   none is needed. This is the `PASS_PRODUCTION` verdict.
4. **Production closures had no path for Build 2.** FM rows could close on committed
   production evidence (`evidence_FMGATE_0417f35/`), but Build 2 rows could not. Added
   `BOARD_CLOSURES.json` and `_closures()` (`completion_board_final.py:542`). A closure is
   accepted only when all of these hold:
   - the ledger itself says done;
   - every evidence file exists;
   - the `/health` read taken at the same time names the deployed commit;
   - every named test exists.
5. **The verify glob caught `/api/verify/smoke`.** `prod_api_verify_*` matched the smoke
   reading, so the board read the wrong file. Narrowed to `prod_api_verify_2*`.
6. **Spot-audit hook.** `BOARD_AUDIT.json` with `apply_audit()` (`completion_board_final.py:519`).
   It can only move a row down. A downgraded row comes back only through `reclosed`, which
   must name tests that exist.

Tests for these rules: `tests/test_w4_board.py`
