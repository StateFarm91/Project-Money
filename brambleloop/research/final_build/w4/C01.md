# W4-C01: build-side integration authority, review, handoffs and collaboration

Branch `claude/w4-C01`, cut from `origin/claude/w4-INTEG8` at b6239f17. Owner of `ops/` for
this cluster. Every change is local build tooling or the pre-push hook path: nothing deploys,
pushes on anyone's behalf, writes to Etsy, spends, or touches the production database. The
production push path (`ops/deploy_guard.py check`, `ops/deploy.sh`, the owner's per-SHA
approval) is unchanged; F-711 adds a rule only for `claude/w4-INTEG*` refs.

Requirement text is quoted from `research/final_build/master_v1.1.txt`. Each row: one test that
fails at b6239f17 and passes on this branch, run as a named suite at nice 19.

## Rows built

### F-711 Single Integration Authority (ef40c78c)
"There is one authoritative integration path. External AI workers may propose, implement or
review isolated work but cannot independently redefine company state, merge conflicting work
or deploy outside granted authority."
- `ops/integration_authority.py`, called from `deploy_guard.pre_push` (so from the installed
  `ops/hooks/pre-push`) for every `claude/w4-INTEG*` ref: only `BRAMBLELOOP_ROLE=integrator`
  may update it, only by fast-forward (an unprovable remote commit is refused), never delete.
  Lanes stay free. If the rule module cannot be loaded the push is refused.
- Test `tests/test_w4_c01_integration_authority.py`: real hook, bare origin. At b6239f17 the
  hook passes a worker push onto INTEG as NOT_A_DEPLOY (fails). Regressions:
  `test_deploy_path`, `test_deploy_guard`, `test_rc1_own_release` green.
- **Integrator action:** once this is integrated and the hook is installed
  (`ops/install_hooks.sh`), the integrator session exports `BRAMBLELOOP_ROLE=integrator`
  before pushing an INTEG branch.

### F-865 Bounded Parallelism (fad3afa1)
"Use disjoint ownership and one integrator; optimize for integrated tested work per resource
window, not maximum agent count."
- Disjoint ownership (F-457) and one integrator (F-711, `ops/integrate.py`) existed. Added: the
  lane registry refuses a new live work lane past `BRAMBLELOOP_MAX_WORK_LANES` (default 6, the
  owner's 4-6 worker directive); `survey()["throughput"]` reports lanes integrated per 24 h per
  lane slot.
- Test `tests/test_w4_c01_parallelism.py`. Regressions: `test_board_restart`,
  `test_reliability_ledger`, `test_w3_suite_job_identity`, `test_w4_close5_rows`,
  `test_w4_fmbatch1_{context_pack,deadlock,dupwork,lane_stop,integrate}` green.

### F-861 Repository Is Shared Memory, F-862 Durable Handoffs, F-863 Context Is a Cache (e9e5b2dd)
"Critical state lives in Git/database/evidence artifacts, not conversation context." /
"Long AI-development tasks persist objective, branch/head, decisions, defects, tests,
unfinished work and next actions." / "Persist conclusions before context pressure and reread
durable state after compaction/restart."
- `ops/handoff.py` `write` (every field required, branch/head from git, DURABLE only when the
  head is on a remote and nothing tracked is uncommitted), `conclude` (persisted when reached),
  `resume` (reread + re-verify the head against the remote: AT_HEAD / MOVED_AHEAD / DIVERGED /
  MISSING). The heartbeat loop (`ops/HEARTBEAT_PROMPT.md` step 3) resumes from it.
- Test `tests/test_w4_c01_handoff.py`. Regressions `test_deploy_path`,
  `test_cert_claude_independence` green.

### F-714 Independent Review, F-866 Independent Model Review (960e285e)
"High-risk customer-facing, financial, marketplace, security, infrastructure and Product Truth
work may receive independent adversarial review by a different model/agent before promotion."
/ "A second model may adversarially review evidence without becoming certification authority."
- `ops/review.py`: closed high-risk path table (all six classes), review records in
  `research/final_build/REVIEWS.jsonl` (self-review refused, `certifies` always false and
  refused if set, `second_model` recorded). `ops/integrate.py` refuses a high-risk lane without
  a NO_BLOCKERS review of exactly its head, or with BLOCKERS on it. A different agent is
  required; a different model is recorded, not required ("different model/agent"), so no
  second provider is needed.
- Test `tests/test_w4_c01_review.py` (at b6239f17 the risky lane merges unreviewed).
  Regressions `test_w4_fmbatch1_integrate`, `test_w4_fmbatch1_task_contract` green.

### F-715 Evidence Resolves Disagreement (4b4d6837)
"Model prestige never decides a technical disagreement. Resolve competing proposals using
reproducible tests, primary evidence, Product Truth, real marketplace/customer outcomes and
measured economics."
- `ops/disagreement.py`: evidence of exactly those kinds (a test only with a repository path
  and its rerun command); deterministic `resolve` that never reads proposer or model.
- Test `tests/test_w4_c01_disagreement.py`.

### F-716 Collaboration Workspace (ea2fd902)
"Brambleloop Studio exposes proposer, implementer, reviewer, disagreement, evidence, tests,
cost, accepted/rejected approach and final integration result for important
multi-agent/model work."
- `ops/workspace.py LANE [--md]`: joins the above records per lane; PRESENT with source or
  MISSING; cost UNMEASURED, never zero.
- Test `tests/test_w4_c01_workspace.py`. Regression `test_w4_fmbatch1_session_log` green.
