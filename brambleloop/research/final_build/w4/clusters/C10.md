# C10 — Marketing/Growth: paid-media planning and credits

Branch `claude/w4-C10`, cut from `origin/claude/w4-INTEG7` e584ff01. The rows come from §C10
of `origin/claude/w4-FMBATCH2:brambleloop/research/final_build/w4/CLUSTERS.md`. All new code
is in `src/brambleloop/growth/`. `commerce/paid_media.py` and `commerce/bundles.py` are used
but not modified.

## Hard limits, enforced

- **No campaign or setting is ever touched.** Nothing creates, activates, funds or changes a
  campaign or an Etsy Ads / Offsite Ads setting. There is no ads executor, and none was added.
- **Every output is SHADOW.** Every plan and ledger entry has `phase: SHADOW` and
  `executed: False`.
- **Spend gates are unchanged.** Spend still passes `ads_readiness.propose` (Finance challenge,
  the hard ceiling in code, an owner item) and, if an executor ever exists,
  `paid_media.authorise_spend` (phase, owner authority and caps). C10 adds nothing that calls
  either.
- **Enforced by test.** `test_c10_modules_cannot_spend_or_reach_the_network` applies the AST
  rules of `test_v11_ads_no_execution` to every new module: no network or integration
  imports, no `authorise_spend` / `enqueue` / `reserve` / HTTP calls, and no function named
  like an executor.

## Existing work found before starting

- **`growth/ads_readiness.py`** (lane H): readiness, economics, proposals, the Finance
  challenge, and `hard_ceiling`, which includes the Plus credit cap at the official US$5.
- **`commerce/search_policy.ads_plan_findings`**: the F-264 / F-265 thresholds as findings,
  read from the watched advertising reading. They are UNVERIFIED there, because the Etsy Ads
  help page returns 403.
- **`commerce/paid_media.py`**: caps, `should_pause`, `may_scale`, `authorise_spend`.
- **`finance/credits.py`**: a generic provider-credit wallet.
- **`commerce/cross_sell.graph`** (F-775 graph half, W4-AGENTS C3): related, bundles,
  collection, tutorials, materials and next projects. Attach rate was UNMEASURED.

C10 builds on these and does not restate them. No new table was added: the ledger uses
`core.models.Experiment` with kind `paid_ads`.
