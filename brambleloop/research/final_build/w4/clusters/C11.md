# C11 — Education and content

Branch `claude/w4-C11`, cut from `origin/claude/w4-INTEG7` 2aeb177f. Rows and file set
(`src/brambleloop/learn/`) come from §C11 of
`origin/claude/w4-FMBATCH2:brambleloop/research/final_build/w4/CLUSTERS.md`.

Before starting I searched INTEG7, FMBATCH1, FMBATCH2 and INTELREC for these IDs; no work on
them was found. The existing pieces the matrix calls PARTIAL are reused rather than restated:
`Lesson.spec` and its revision hash, `validate_spec`, `swatch`, `technique`, `graph_feeds`,
`curriculum`, `cir.twin` and `cir.stitches`.

Tests are in `tests/test_w4_c11_learn.py`, one per row. Each test fails before its change
(the module it imports did not exist) and passes after. No new tables were added: durable
records use existing Learn rows (`learn_lessons`, `learn_nodes`, `learn_gaps`).

| ID | module | what it enforces |
|---|---|---|
| F-804 | `learn/formats.py` | Ten formats rendered from `Lesson.spec` by fixed templates, each carrying its revision. `drift()` refuses any number or stitch name the spec does not state. It works in the lesson's terminology and matches the longest name first, so a UK "double crochet" in a US lesson is caught. Only approved lessons are rendered, unless an editor asks for a preview. |
| F-809 | `learn/gauge.py` | Covers stitch and row gauge, hook advice, tension consistency, blocking and yarn substitution (using the twin's yardage and tolerance, and refused across weight classes). `fit` rebuilds the `cir.twin` at the learner's gauge, so it is the same computation as the stated size. |
| F-813 | `learn/video_contract.py` | A video that covers only some sizes, or another version, needs a scope statement generated from the records; `check_statement` verifies it. `standalone` refuses a written pattern that hands steps to a video, unless the product promises a video-led product. |
| F-816 | `learn/linking.py` | A link needs a stated reason: a prerequisite (from a recorded edge), a technique the pattern uses, apply-it, or answers. Shared title words never count. At most 5 links per page, and the anchor is the target's title. Links are tested by click-through: at 200+ impressions a link is kept or dropped; below that it is UNMEASURED. |
| F-817 | `learn/seo.py` | An independent brief per lesson: intent, title and meta within length limits, HowTo or FAQPage schema, FAQ opportunities from recorded search phrases, and an update cadence set by intent. Title and meta are checked for drift and for unearned claims ("easiest", "best"); a failing brief is REFUSED. |
| F-818 | `learn/freshness.py` | Monitors stale links, terminology against the taxonomy, broken media (UNKNOWN when no index is supplied), obsolete products, rule regressions, new support evidence on covered topics, and adjacent support gaps. `update` refuses a spec that fails validation, drifts, or still has findings. Otherwise it saves a new revision with reviews reset. |
| F-823 | `learn/beginner_sim.py` | Eight beginner mistakes. Where the swatch allows, each is simulated: a dropped stitch must trip the compiler, a skipped turning chain must change the written text, and 15% tighter tension must move the twin width by more than 2%. Foundational lessons must leave nothing UNGUARDED. |
| F-829 | `learn/teaching_loop.py` | OBSERVE → HYPOTHESIS → EXPERIMENT → MEASURE → VALIDATE → PROMOTE/REJECT, stored as `learn_nodes` of kind `teaching`, and each stage must follow its predecessor. A variant must keep the technical truth (a `sequencing` change may reorder steps but not alter them) and must not drift. MEASURE needs n ≥ 30. A lesson that changes revision during the experiment is rejected. PROMOTE saves a new DRAFT revision that must be reviewed again. |
| F-771 | `learn/ladder.py` | A ladder needs 2+ features that only the paid product has; otherwise it is DUPLICATE. |
| F-811 | `learn/ladder.py` | The free and paid items must share a topic, or the ladder is NOT_RELEVANT. Teaser steps, empty teaching, a mid-teaching CTA, or more than one CTA make it DECEPTIVE. |
| F-772 | `learn/distribution.py` | One canonical record: the newest certified version, its release hash, price, file sha256s and claims. Every channel payload is derived from it, and every channel is CLOSED (nothing is sent). `sync` reports IN_SYNC, UPDATE_PENDING (with the differences) or UNKNOWN when a channel was not observed. |
| F-810 | `learn/lead_magnets.py` | A lead magnet is refused without a goal, provenance (with a sha256, and a licence for licensed material) and a version. Versions are immutable. Attribution counts only signups with consent (CASL), and is UNMEASURED when there is no record. |

## Known limit (F-804, F-829)

`formats.drift` works on sets. A number counts as "stated" if it appears anywhere in the spec.
For example, the hook size 4 makes "Chain 4" pass the check. The drift check catches numbers
the spec never states; it does not catch a stated number used in the wrong place. Placement is
protected separately: F-829 compares each step's stitch, repeat, consumes and produces exactly,
and F-804 renders counts only from the spec's fields.
